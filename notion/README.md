# Notion templates

Two ready-made tables you can import into our Notion page.

| File | What it becomes in Notion |
|---|---|
| `task-tracker.csv` | A table of tasks: status, who's on it, points, and due date |
| `team-progress.csv` | A daily check-in log: what each person did, what's next, and anything blocking them |

## How to import

1. Open the Notion page and type `/` → choose **Import** (or **⋯ → Import**).
2. Pick **CSV** and select the file.
3. Notion creates a table. Then tidy up the column types:
   - **Status** → change to a *Status* property (To Do · In Progress · Done)
   - **Assignee** / **Member** → change to a *Person* property
   - **Date** → change to a *Date* property
4. Optional: add a **Board** view grouped by Status to get a drag-and-drop board.

## Tips

- All times are **Cairo time (12-hour AM/PM)**.
- For each new weekly assignment, add its tasks to the tracker and set the **Assignment** column (Week 2, Week 3, …).
- Keep check-ins short: one row per person per day.
