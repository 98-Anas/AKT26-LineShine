# Project tracker

One simple way to keep track of **tasks, team progress, learning and risks**. It comes in two versions, so use whichever you like.

| | Blank template (any project) | Filled in for Team LineShine |
|---|---|---|
| **Excel** | [excel/Project_Tracker_Template.xlsx](excel/Project_Tracker_Template.xlsx) | [excel/LineShine_Tracker.xlsx](excel/LineShine_Tracker.xlsx) |
| **Notion** | [notion/template/](notion/template/) | [notion/lineshine/](notion/lineshine/) |

## What's inside

| Part | What it's for |
|---|---|
| **Tasks** | Everything that needs doing: who, status, priority, due date, progress |
| **Timeline** | A Gantt chart of the tasks (drawn automatically in Excel; a Timeline view in Notion) |
| **Milestones** | The big checkpoints, with % done |
| **Check-ins** | A short daily update from each person: what I did · what's next · what's blocking me |
| **Learning** | Topics to learn, with free links; everyone marks their progress |
| **Risks & Issues** | What could go wrong, how bad it is, and the plan |
| **Dashboard** (Excel) | Everything at a glance: % done, overdue tasks, project health, charts, one-click member view |

## Using the Excel version

1. Open the file. The **Start Here** sheet has buttons to every sheet.
2. Go to **Settings** and type your project name, dates, time zone and team.
3. Add tasks on **Tasks**. Pick owner, status and priority from the drop-downs.
4. Check the **Dashboard**. It updates by itself.

**Blue text** = type here · **grey** = calculated · **purple italics** = example rows you can delete.
Hover over any column title to see what goes in it.
To work as a team, put the file on OneDrive or Google Drive so everyone edits the same copy.

## Using the Notion version

Open the `README.md` inside [notion/template/](notion/template/README.md) or [notion/lineshine/](notion/lineshine/README.md). It walks you through importing the five CSV tables and setting up the board and timeline views (about 10 minutes, once).

## Regenerating the files

The files are generated by [`scripts/build_tracker.py`](../scripts/build_tracker.py). To make fresh copies:

```bash
uv run --with openpyxl python scripts/build_tracker.py
```
